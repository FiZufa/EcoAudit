> what does it mean by passing confidence thereshold?

● The conf parameter filters out weak detections.

  YOLO assigns a confidence score (0–1) to each detection — how sure it is that the object is what it thinks it is.

  - conf=0.5 (default) → only return detections where the model is ≥50% confident
  - conf=0.3 → return more detections, including less certain ones
  - conf=0.8 → only return detections the model is very confident about

  Example:

  Say the model scans an image and finds:

  ┌─────────┬────────────┐
  │ Object  │ Confidence │
  ├─────────┼────────────┤
  │ Plastic │ 0.87       │
  ├─────────┼────────────┤
  │ Can     │ 0.45       │
  ├─────────┼────────────┤
  │ Trash   │ 0.21       │
  └─────────┴────────────┘

  - At conf=0.5 → returns only Plastic
  - At conf=0.3 → returns Plastic + Can
  - At conf=0.2 → returns all three

  Rule of thumb:
  - Lower conf = more detections, more false positives
  - Higher conf = fewer detections, more accurate

  0.5 is a safe default for most cases.
